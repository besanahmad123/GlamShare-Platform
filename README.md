# 👗 GlamShare — Digital Fashion Rental Ecosystem

**GlamShare** is a software engineering project designed to address financial waste and
disorganization in the local occasion-dress market through a centralized, peer-to-peer (P2P)
dress rental and reservation platform.

## 📊 Market Insights
Based on a 40-respondent survey conducted for requirement collection:
- **90%** own occasion dresses they rarely wear after the first use.
- **55%** have experienced, or are concerned about, double-booking conflicts on informal social platforms.
- **50%** struggle with scattered information on size, price, and availability.
- **72.5%** confirmed a real-time interactive calendar is a critical feature.

---

## 🏗️ Key Features
- 🔍 **Smart Discovery** — multi-criteria search and filtering by occasion, size, color, fabric, and price.
- 📅 **Reliable Booking** — interactive availability calendar with automatic double-booking prevention.
- 📊 **Owner Dashboard** — listing management, booking calendar, and revenue tracking for dress owners.
- 🛡️ **Trust & Safety** — built-in ratings and review system between renters and owners.
